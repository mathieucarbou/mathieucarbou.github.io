# Java

JVM tooling I maintain — Maven plugins, Guice extensions and small utility libraries.

## 🧰 License Maven Plugin

The original Maven plugin for managing source-file license headers. It supports checking, formatting and removing headers, reusable templates, custom properties, multi-licensing and dependency-license enforcement.

[Documentation](https://mathieu.carbou.me/license-maven-plugin/){ .md-button } [Source code](https://github.com/mathieucarbou/license-maven-plugin){ .md-button }
